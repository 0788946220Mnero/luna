نظام المهارات — كيف تضيف أسلوب بيتك
====================================

ما هي المهارة؟
  ملف Markdown فيه المعرفة الإجرائية التي لا يعرفها النموذج عن سياقك:
  الأنماط الصحيحة، الأخطاء الشائعة، المكتبات المتاحة، وقائمة تحقق نهائية.

المهارات المدمجة (تُشحن مع المشروع):
  python-code          كود Python بجودة إنتاج
  frontend-web         واجهات ويب مع دعم العربية وRTL
  api-backend          واجهات برمجية آمنة
  docs-writing         توثيق يقرؤه الناس
  data-files           JSON وCSV وSQL — مع فخاخ العربية
  restaurant-systems   أنظمة المطاعم بالسياق الأردني

كيف يستخدمها الوكيل؟
  1. قائمة المهارات تُحقن في توجيهه تلقائياً
  2. عند تسلّم مهمة، يُرشَّح له الأنسب حسب كلماتها
  3. يقرأ المهارة بـ read_skill قبل أن يكتب أي ملف

إضافة مهارتك الخاصة:
  أنشئ مجلد skills/ داخل مساحة عملك، وضع فيه ملفاً مثل:

    skills/kenzi-style.md
    ---
    name: kenzi-style
    description: أسلوب كنزي في بناء الشاشات
    triggers: كنزي, kenzi, شاشة, واجهة كاشير
    ---

    # أسلوب كنزي
    - الألوان الأساسية: #C8102E و #1A1A1A
    - كل شاشة كاشير تحتاج زر إلغاء واضح أعلى اليمين
    - الخط: Cairo بحجم 16px كحد أدنى للقراءة من مسافة

  مهارة باسم مطابق لمهارة مدمجة تحلّ محلها.

التحقق الإجباري
===============

كل ملف يُكتب يُفحص فوراً حسب امتداده:
  .py            تحليل نحوي + ruff
  .js .ts .jsx   node --check أو فحص أقواس
  .json .yaml    تحليل كامل
  .html .vue     توازن الوسوم + alt + lang
  .css .scss     توازن الأقواس
  .md            كتل الكود والعنوان

عند فشل التحقق ترجع الأداة خطأً صريحاً، والتوجيه يُلزم الوكيل بإصلاحه
قبل أي خطوة أخرى وقبل إعلان الانتهاء.

الوضع الصارم (اختياري):
  في agent.yaml:
    validation:
      strict: true
  عندها لا يُحفظ أي ملف لم يجتز الفحص إطلاقاً.

أداة مستقلة: validate_file للتحقق من أي ملف في أي وقت.
